# Система автоматизации склада и магазина (Store & Warehouse ERP/POS)

Полнофункциональная веб-система для автоматизации розничной торговли, складского учета и кассового обслуживания (POS).

## Стек технологий

- **Frontend**: Next.js 14 (App Router), React, TypeScript, Tailwind CSS, shadcn/ui, Zustand, TanStack Query, Recharts, Lucide Icons.
- **Backend**: NestJS, TypeScript, REST API, Passport JWT + Refresh Tokens, RBAC, Argon2, Class-Validator, Helmet, CORS, Throttler.
- **Database & Cache**: PostgreSQL 16, Prisma ORM, Redis.
- **Storage**: MinIO / S3 (с локальным fallback-хранилищем `uploads/`).
- **Инфраструктура**: Docker, Docker Compose, Nginx Reverse Proxy.

---

## Роли и функциональность

### 1. Администратор (Admin Hub)
- **Аналитическая панель**: сводка выручки, чистой прибыли (выручка минус себестоимость), среднего чека, графики динамики за 7/30 дней (Recharts), лидеры продаж, структура оплат (наличные / карта).
- **Каталог товаров**: добавление, редактирование, артикул (SKU), штрихкод (EAN-13), категория, цена закупки, цена продажи, остаток, фото.
- **Склад и остатки**:
  - Мониторинг остатков по складам и торговым точкам;
  - **Приход товара** (поступление от поставщика, оприходование);
  - **Списание товара** (порча, брак, списание);
  - **Перемещение товара** (между складами и торговым залом).
- **История продаж**: полный реестр кассовых чеков, просмотр детализации, печать чека (80мм термопечать), оформление возврата.
- **Персонал**: учет администраторов и кассиров, установка персональных 4-значных PIN-кодов.
- **Журнал аудита**: фиксация действий пользователей, создание/изменение товаров, складских документов и входов в систему.

### 2. Кассир (POS Terminal)
- Сенсорный и клавиатурный интерфейс для быстрой работы на кассе.
- **Открытие кассы**: указание разменной суммы на начало дня.
- **Сканирование штрихкодов**: автоматический перехват сканера штрихкодов в любой момент времени.
- **Мгновенный поиск**: по названию, артикулу или штрихкоду.
- **Корзина**: быстрый подсчет, изменение количества (+/-), скидка на чек.
- **Оплата**:
  - Наличные (быстрые кнопки купюр: 100, 500, 1000, 5000 ₽, расчет сдачи в реальном времени);
  - Банковская карта (безналичный расчет).
- **Чек**: печать фискального чека на термопринтер (80мм) или сохранение в PDF.
- **Закрытие смены**: сверка наличных в кассе, расчет расхождений (недостача / излишек).

## Запуск проекта

### Вариант 1: Запуск через Docker Compose (Рекомендуемый)

Убедитесь, что Docker запущен, и выполните в корне проекта:

```bash
docker compose up -d --build
```

Сервисы будут доступны по следующим адресам:
- **Веб-приложение (Касса + Панель)**: [http://localhost](http://localhost) (или порт 3000: [http://localhost:3000](http://localhost:3000))
- **REST API Swagger**: [http://localhost/api/docs](http://localhost/api/docs) (или [http://localhost:4000/api/docs](http://localhost:4000/api/docs))
- **MinIO Console**: [http://localhost:9001](http://localhost:9001) (`minioadmin` / `minioadminpassword`)

---

### Вариант 2: Локальный запуск без Docker

#### 1. Запуск Backend (NestJS):
```bash
cd server
npm install
npx prisma generate
npx prisma db push
npx ts-node prisma/seed.ts   # Заполнение тестовыми товарами и пользователями
npm run start:dev
```
*API запустится на `http://localhost:4000/api`, Swagger на `http://localhost:4000/api/docs`.*

#### 2. Запуск Frontend (Next.js):
```bash
cd client
npm install
npm run dev
```
*Интерфейс будет доступен на `http://localhost:3000`.*
